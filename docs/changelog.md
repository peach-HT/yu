# 版本记录

## v13 无金额版 · 2026-11-25

- 所有分类统一去掉金额、次数录入与展示；储值卡分类保留。
- 移除消费扣减、余额校正、金额汇总与当前金额语义解析。
- 语音仅回填使用日期和描述；含金额的自然描述不触发计算，明确余量维护请求提示不支持。
- 新权益和使用事件不产生余量字段。旧字段和事件兼容保留，旧消费与校正只读，防止撤销再次修改余量。
- 编辑、归档也推进记录版本；编辑面板增加存储快照检查。
- 测试收敛为35项，新增模拟DOM流程检查；文档区分当前能力与历史探索。
- 本次发布目标为GitHub仓库；既有Sites演示仍为v12，尚未同步。
