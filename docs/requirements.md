# 首版需求与验收条件

## 核心任务

跨平台持有多项权益的用户，可以集中录入名称与截止日期，准确找到最近到期的有效权益。日期尚不清楚时允许暂缺，明确标记待补充，不自动视为长期有效。

## 范围与验收

| 范围 | 验收条件 |
| --- | --- |
| 录入与编辑 | 可以创建、保存并重新打开权益；编辑不会意外清空已有信息 |
| 期限计算 | 到期当天与已过期区分；3天、7天等边界按日期正确计算 |
| 清单与概览 | 有截止日期的有效权益按临近顺序展示；概览排除已过期和已归档项 |
| 特殊期限 | 未知日期与长期有效有不同文字；过期权益进入单独区域 |
| 记录面板 | 语音回填内容可编辑；确认前不扣除金额；不支持语音时可手动完成 |
| 金额语义 | “吃饭花了20，饮料4”合计24；“消费35.5，其中吃饭30，饮料5.5”不重复相加 |
| 次卡 | 不要求填写剩余次数；记录使用不扣减兼容保留的历史次数 |
| 日历与归档 | 使用记录可在相应日期查看；归档权益可恢复 |
| 示例模式 | 始终明确标注示例，退出示例后可开始个人记录 |
| 保存异常 | 保存失败不提示成功；已有数据读取异常时暂停写入，避免覆盖原记录 |

以上为当前验收口径，不代表每一项均有外部用户观察数据。规则和模拟事件由自动检查覆盖，真实语音转写及设备兼容性仍需实机确认。

## 非首版范围

服务方实时同步、主动推送、账户与云同步、App使用入口跳转、截图导入及批量盘点。
