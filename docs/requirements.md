# v13需求与验收条件

核心任务：集中录入权益名称与截止日期，准确找到最近到期的有效权益。所有分类均不维护次数或金额。

| 范围 | 验收条件 |
| --- | --- |
| 录入与编辑 | 会员、次卡与储值均只填写名称、期限及选填信息，无金额、次数或校正选项 |
| 日期 | 真实日期与合理区间；今天、3天、7天等边界正确 |
| 清单概览 | 按临近期限排序；概览排除过期和归档权益 |
| 特殊期限 | 未知、长期有效和已过期分别呈现 |
| 语音与手动记录 | 回填日期和原话，可编辑并确认保存；语音不可用时手动完成 |
| 不维护余量 | 口述金额只保留描述；明确余额校正或充值请求提示不支持，不生成金额更新 |
| 记录撤销 | 仅撤销版本匹配的新使用记录，不修改任何旧余量 |
| 旧数据 | 加载不写回；旧字段保留但不展示结构化余量，旧消费／校正只读回顾 |
| 异常保护 | 损坏状态暂停写入；编辑或打卡快照变化时拒绝覆盖；保存失败不提示成功 |
| 日历与示例 | 日历可查看新旧记录，示例模式明确标识且没有余额数据 |

自动检查覆盖规则、模拟语音与模拟DOM流程；新版尚需真实浏览器、设备和外部用户验收。无后台主动通知、服务方同步、账户、云同步、截图导入或App入口跳转。
