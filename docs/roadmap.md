# 后续规划

v13聚焦权益与期限，不恢复金额或剩余次数维护作为首版前提。

| 方向 | 要解决的问题 | 验证方式 |
| --- | --- | --- |
| 新版试用与回访 | 去掉余量后是否仍满足实际需求 | 找目标用户完成录入、查临期与修改期限；记录阻碍并在一周后回访 |
| 连续录入与可中断盘点 | 查询多个原平台后再录入的成本 | 观察三项真实权益的查找与录入，分开记录耗时 |
| 截图识别名称和截止日期 | 重复录入信息 | 使用脱敏截图验证日期覆盖、识别与人工确认成本 |
| 到期通知 | 当前需主动打开页面 | 验证触达需求、授权意愿与实现方式 |
| 服务方同步与入口跳转 | 部分决策和使用仍需原平台 | 确认官方接口、授权及入口稳定性，不预设通用接入 |

下一步先验证持续维护意愿、与日历或备忘录的比较，以及缺少余量对真实决策的影响。以上为候选方向，尚未实现。
