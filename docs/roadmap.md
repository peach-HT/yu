# 后续规划

当前版本优先提供可运行、可演示的权益清单。以下方向尚未开发，不作为首发前提。

| 优先探索的方向 | 问题 | 下一步验证 |
| --- | --- | --- |
| 连续录入与可中断盘点 | 用户希望一次整理完权益，但需要逐个进入原平台查询 | 观察三张真实权益的查找与录入过程，识别主要耗时环节 |
| 截图识别后确认 | 查询后仍需重复输入日期 | 收集脱敏示例，验证信息覆盖、识别准确性与确认成本 |
| 到期通知 | 用户目前必须主动打开页面 | 验证通知需求、授权意愿及可行触达方式 |
| 服务方同步与使用入口跳转 | 使用和查余量仍需进入原平台 | 确认官方接口、授权与入口稳定性，不预设可通用接入 |

产品验证优先关注持续维护意愿、与日历和备忘录的比较，以及缺少次数是否影响使用或续费决策。对查询或录入流程的优化，应先确定主要成本在哪里。
